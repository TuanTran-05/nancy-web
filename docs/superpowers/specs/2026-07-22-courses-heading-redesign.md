# Courses Heading Redesign

## Goal

Redesign the courses section heading to match the provided reference image.

## Approved Direction

Use the text `KHÓA HỌC DÀNH CHO MỌI ĐỘ TUỔI`.

The heading is split into two visual parts:

- `KHÓA HỌC DÀNH CHO`: large uppercase dark blue text.
- `MỌI ĐỘ TUỔI`: large uppercase white text inside a rounded orange capsule.

Add a small bright blue hand-drawn accent near the capsule's top-right corner to echo the reference image.

## Scope

Only the courses section heading is changed. The course carousel, card content, navigation, images, and section intro remain unchanged.

## Responsive Behavior

On wide screens, the blue text and orange capsule sit on one line when space allows. On smaller screens, they wrap naturally with balanced spacing and no horizontal overflow.

## Validation

Verify the page renders in a browser, and check desktop and mobile widths for heading fit.
